# 吃灰博物馆 🏛️

> 把你买错的垃圾陈列成永久藏品，让这面越来越灰的墙替你劝住下一次手痒。

**在线体验**：[dust-museum-1024.app.workbuddy.host](https://dust-museum-1024.app.workbuddy.host/?sharecode=FJYUST4BF2)

一个纯前端的「反消费主义实验」网页应用：买错了什么，就拍照「捐赠」进馆。照片随真实天数自动积灰褪色，系统算出每件展品的**单次使用价判决书**，还会换算成「你为之上了几天班」。藏品只进不出，概不赎回。

**1024 造物挑战参赛作品 · 由 WorkBuddy AI 搭档全程协作开发**

---

## ✨ 核心玩法

| 系统 | 说明 |
|---|---|
| 📸 **捐赠入馆** | 拍照 + 价格 + 类别 + 购买原因，30 秒入馆，自动生成捐赠证书（Canvas 绘制） |
| 🌫️ **积灰滤镜** | `dust(天数)` 纯函数映射 CSS filter：第 1 天彩色，第 210 天接近全灰——时间本身就是惩罚 |
| 💸 **单次使用价** | 价格 ÷ max(次数, 1)，换算成时薪（月薪÷176h）对应的工作天数 |
| 🚪 **展厅陈列** | 8 个购买原因独立成厅（跟风/宏伟计划/大促/别人都有/一时上头/送礼/入坑/理想生活）+ 原封未拆特展 + 镇馆之宝 |
| 🎫 **可分享物料** | 捐赠证书 / 藏品明信片（每次随机盖章+登记号）/ 门票票根，Canvas 实时生成 |
| 🆘 **手痒急救** | 下单前打开看馆藏账单，累计拦截手痒次数 |
| ⚙️ **自定义** | 类别（18 预设）与购买原因（8 预设）均支持用户自建，自建原因独立成厅、自动署名「一时兴起的××」 |

## 🧭 设计思想

**「数据即 UI」**：用户只录入 7 个原始字段（名称/价格/类别/原因/次数/照片/时间），所有统计——单次使用价、吃灰天数、涉案总额、原因占比——全部由 `stats()` 实时派生。存储里只有事实，没有观点，永无不同步。

**「时间即惩罚」**：不靠弹窗说教，照片本身随天数褪色。积灰滤镜是一个纯函数，天数进、灰度出，公平且不可逆。

**「只进不出」**：没有删除入口（只有馆长办公室的全馆清空）。买错的事实无法撤回，产品机制与产品人格一致。

**「戏仿而非说教」**：每个类别配材质隐喻展签（潮玩手办→「树脂、涂装，与柜子里的编制」），每个购买原因配策展人按语（理想生活厅→「买下它们的那一刻，你已经是另一个人了。后来你变回来了。」）。用博物馆的庄重腔调陈列消费主义的残骸，幽默感即劝退力。

## 🛠️ 技术栈

- **零依赖单页**：原生 HTML/CSS/JS（ES5 风格，Chrome 61+ 基线），无框架无构建
- **localStorage 持久化**：单键 `dustMuseum.v3` 存全部数据，带版本化迁移通道 `upgrade()`，永不覆盖用户数据
- **Canvas 2D**：证书/明信片/门票三套绘制器；照片入场时前端压缩（640px, JPEG q0.72）
- **积灰滤镜**：CSS filter 组合，纯函数无副作用
- **离线可用**：无任何网络请求（小红书小工具容器版），更新检查在 Web 环境自动探测

### 小红书小工具版

本仓库同时适配了[小红书小工具容器规范](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)：

- 脚本外置（容器 CSP 禁内联脚本）、无 `window.prompt` / `navigator.clipboard` 等被禁 API
- 保存图片优先走官方桥 `window.xhs.miniTool.saveImageToPhotosAlbum`
- 打包产物：`index.html + app.js` 位于 zip 根，全包 < 30KB（上限 10MB）

## 🚀 本地运行

无构建步骤，任意静态服务器指向本目录即可：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```
